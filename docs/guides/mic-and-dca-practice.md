# Mic changes and DCA cues: sourced practice and planning rules

## Sources and exact supporting evidence
Retrieved official documentation and independent practice articles. These establish general practice, not a guarantee for a specific production. No theatre video was watched/transcribed and no live console behaviour was tested.

1. TheatreMix features: https://theatremix.com/features
   - “Any controlled channels not assigned to a DCA in a cue will be automatically muted.”
   - “White = the DCA assignment changes in the next cue” / “it's best to press go when the DCA fader is down”.
   - “Green = the exact same channels (and positions and profiles) are assigned to this DCA in the next cue” / “it's safe to press go when the DCA fader is up”.
   - Yellow indicates profile changes; press GO while actor not speaking. Magenta indicates ensemble moves; GO with all magenta DCAs at the same level.
   - “Important: TheatreMix only uses ensemble definitions at the time when channels are assigned to a DCA: once a DCA's channels have been assigned in a cue TheatreMix will not track any changes made in ensemble setup.”
   - “All changes to a channel's stored processing types will be automatically captured and updated in the active profile, even when editing is locked.” Run line-checks cue before modifying processing during checks.
   - “Important: TheatreMix will not mix the show for you!”
2. Usage FAQ: https://theatremix.com/faq-usage
   - “It's generally better to double mic the lead actors who won't have time to get a new microphone fitted during the show. There is no point having lots of spare microphones if there is no time to fit them to actors between scenes.”
   - “When using TheatreMix the show data is split across two places: the TheatreMix file on computer and the base scene on the console (plus any snippets or additional scenes on the console).”
   - FAQ suggests a side-stage emergency handheld as a standard non-TheatreMix-controlled channel due to gain-structure differences. This is a recommendation to review, not a universal patch mandate.
3. Mixing FAQ: https://theatremix.com/faq-mixing
   - “The general aim is to create just enough cues for the show: too many cues can result in excessive go button hits, not enough cues can result in lingering stale DCA assignments.”
   - “When planning out cues it can be useful to think in terms of French Scenes.” Some passages need multiple cues, others none; songs usually need separate cues.
   - Consistent assignments are generally preferred, with script-order assignments useful for busy dialogue. Ensembles on rightmost controls can assist balancing leads/ensembles.
   - Only raise microphones while used; live fader moves adapt to performance better than abrupt line mutes. A published50–100 cue example is descriptive, not a quota.
4. SoundGirls, Mixing for Musicals: https://soundgirls.org/mixing-for-musicals-2/
   - “The DCAs act as remote controls for the channel faders.”
   - Desk scenes correspond to “changes in what the audience needs to hear, rather than scenes in the script”.
5. Theatrecrafts paperwork: https://theatrecrafts.com/pages/home/topics/sound/sound-design-paperwork/
   - Mic plot: “A chart showing who is using each radio microphone during each scene, and when swaps happen.”
6. Shure placement: https://www.shure.com/en-US/insights/top-mic-placement-tips-for-theater
   - “It's a good idea to meet with the costume designer as early as possible so that microphone placement, transmitter size, and wardrobe considerations can be discussed before rehearsals begin.”
   - “If a microphone is positioned the same way every night, EQ, gain, and overall sound quality will remain more consistent throughout a production.”
7. DPA fitting: https://www.dpamicrophones.com/mic-university/how-to-mic/how-to-mic-speech-on-stage-with-headworn-and-miniature-mics/
   - Headworn placement close to source needs less gain; repeatable secure fitting matters. DPA describes dual-ear mounting for high movement and omni headsets as forgiving of placement in controlled musicals. These are context-specific microphone choices, not an instruction to overrule Jayden's design.
8. TSDCA documentation framework: https://tsdca.org/resources-2/
   - Documentation is “a flexible framework of document forms and practices for practical communication”, not a mandatory exhaustive set.
9. SoundGirls production case: https://soundgirls.org/tag/top-ten-high-school-musicals/
   - “Since I had 12 transmitters, the packs could all stay on their dedicated actor, and the A2 would just have to attach the lav as needed.” Distinguish capsule sharing from pack sharing; this anecdote is not a standard minimum equipment budget.

## Engineering synthesis: apply with production-specific confirmation

Keep separate IDs for performer, character, track, capsule/rig, transmitter, RF receiver/output path, console channel, processing profile and DCA. Profiles change processing, not physical ownership. A performer playing multiple roles can retain one rig/pack/channel. A cast change can require actor settings without any hardware handover. Fixed double-mic backup, floating spare and independent emergency handheld are separate failure plans; verify capsule, patch and RF readiness, not just unused transmitter count.

Line-by-line describes fader work, not assignment-cue frequency. Build a state containing independently controllable voices needed until the next safe GO, including sustaining notes, offstage vocals and imminent builds. A soloist should be separated from backing voices when different rides are needed; rebuild ensembles explicitly. Retain local muscle memory where feasible, but allow justified reassignment matching Jayden's corpus. Do not assign unrelated overlapping dialogue to one group merely to fit DCA capacity.

Plan transitions using current and next memberships/profiles/positions. Do not cut sustaining vocals because the next lyric belongs to somebody else. If a changed DCA cannot safely be lowered during the available gap, use another control, defer the change or revise grouping. Multi-DCA memberships require deliberate console-tested behaviour; examples here use disjoint allocation. Availability on a DCA is not proof its fader should remain open.

Keep playback recovery distinct from assignment recovery where needed: skipping/backtracking should not unexpectedly refire tracks. Console scenes must be recall-scoped to avoid overwriting TheatreMix-owned parameters. Preserve base-console backups as well as .tmix backups.

## Physical swap feasibility
No reviewed source establishes a universal60-second hard stop or2–3-minute minimum. Replace fixed defaults in supplied ZIP advice with measured rehearsal timings and production-agreed contingency. Unknown time is unresolved, not zero.

For each operation record:
- outgoing performer/last amplified use (including held/offstage vocals and bows), release landmark and location;
- incoming performer/first required amplified use and ready deadline;
- exact item moved: pack only, capsule only, complete rig, or a processing/patch change without physical transfer;
- routes, crew/A2/wardrobe owner, costume access and adjacent quick changes;
- complete measured task time: travel, access, disconnect/refit, placement/strain relief, RF/battery/listening check, costume restoration, return to entrance and confirmation;
- contingency and fallback if not ready.

Approve only when the available window exceeds repeatable full-operation time plus agreed margin. Avoid double-counting travel already measured. Check crew/location contention: two non-overlapping singers can still have infeasible simultaneous changes needing one A2. Check alternative casts and split tracks separately. An idle pack can be fitted/occupied/reserved and not releasable; inventory minus active singers is not usable spare count.

Prefer principal stability and fewer physical changes over minimum graph colouring. A conflict graph is a lower bound, not an executable backstage plan. Pages are neither timing intervals nor simultaneous-needs evidence by themselves.

## Deliverable paperwork
Produce linked patch/identity table; utilisation plot with amplification and fitted/occupied intervals; A2 handover running order; fitting/performer instructions coordinated with wardrobe; FOH cue ledger and marked script/score; cover/failure deltas; matched revision/approval status. Keep RF assignments factual or TBC, never invented. Assign source page/trigger and confidence to each requirement.
