# Binder

Documentation platform for musical theatre productions. pnpm TypeScript monorepo.

- `packages/*` shared libraries (`@binder/shared`, later `db` and `core`)
- `apps/*` API and web app
- `fixtures` public fixtures and generators

```
pnpm install
pnpm lint
pnpm typecheck
pnpm test
```

Requires Node 24 (see `.nvmrc`) and pnpm 12.
